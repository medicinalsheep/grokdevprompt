# GrokDevPrompt v0.5.1

![GrokDevPrompt Icon](https://github.com/medicinalsheep/grokdevprompt/blob/main/icons/appicon512.png)

**The ultimate spec-driven prompt architect for Grok.**

A powerful, beautiful single-file tool that helps you generate extremely detailed, production-ready prompts for building games, apps, tools, AI systems, and more.

Now with a collapsible **How to use** guide (same style as GrokMusicVideoPrompt), mobile-fixed checkboxes, and a one-tap **Copy link for Grok** opener.

## Key Features

- Clean dark cyberpunk interface (zero dependencies)
- Collapsible **How to use & tips** with Option A / B / C
- **Copy link for Grok** — pastes a ready opener + live tool URL into clipboard
- 15+ project types (Unity, Unreal, VR/AR, AI/ML, Blockchain, Game Mods, Steam integration, etc.)
- Rich common features + custom features input
- Mobile-friendly checkbox grid (visible, tappable, no layout break)
- **Experimental Features** (⚠️ rabbit hole territory):
  - **Truncate or multiple response** mode – clean multi-part output handling
  - **Prompt self-improvement loop** – iteratively evolves this very tool for your project
- Desired visual theme control for the final product
- One-click copy to clipboard

## How to Use

### Option A — Drop the link into Grok (recommended)

1. Open the [live tool](https://medicinalsheep.github.io/grokdevprompt/)
2. Expand **How to use & tips** (or use the button under Generate)
3. Click **Copy link for Grok**
4. Paste into a Grok chat — Grok gets the live URL + a short guided opener

Or paste this yourself:

```
https://medicinalsheep.github.io/grokdevprompt/
```

Then say something like: *"Design a prompt for me using this tool"* (or describe your project).

### Option B — Build the prompt yourself

1. Fill in project basics, features, tech, and constraints
2. Click **Generate Grok Prompt**
3. Copy and paste into Grok

### Option C — Local

Clone or download this repo and open `index.html` in your browser.

## Self-Improvement Loop

When enabled, the tool generates an improved version of itself — more specialized to your project with additional relevant questions, recommendations, and refinements. Each iteration gets smarter. Use 2–3 times for best results on complex projects.
